# 교수님 검토용 프로젝트 요약

초안 · 2026-10-03 · BasinLens CCS

## 연구 질문

CO₂ 저장 후보지 평가에서 불확실한 지질 입력, 물리 시뮬레이션과 공개
모니터링 관측을 연결하면 어떤 평가 결과까지 재현성 있게 설명할 수 있는가?
AI 가속을 사용하더라도 판단에 중요한 압력·plume·질량 오차를 검출할 수 있는가?

## 현재 결과

독립 삼각분포를 가정한 체적 저장용량 Monte Carlo, Q10/Q50/Q90,
민감도와 예시 주의도 규칙을 계산하는 Python 프로토타입이 있다.
v0.2.0에는 입력 사본·환경·seed·소스 지문·결과 해시·보고서를 추가했다.
17개 소프트웨어 테스트와 합성 예제 회귀를 확인했다. 실제 저류층,
압력·다상유동·지진 역산 및 현장 적용은 아직 검증하지 않았다.

## 제안 방법

Sleipner 공개 참조 자료 중 작은 자산부터 출처·좌표·단위를 감사한다.
CO₂–brine 기준 계산을 재현하고 질량 보존·격자와 시간 간격의 수렴성을
확인한다. 관측 plume 경계 또는 QC된 지진 변화와 시뮬레이션을 비교하고,
자료 부족·암석물리 가정·해석의 비유일성을 보고한다. 이후 PhysicsNeMo
surrogate와 실행 자동화를 같은 독립 시험에서 비교한다.

## 검토받고 싶은 질문

1. 초기 연구 범위는 체적 저장량 검증, CO₂ 기준 시뮬레이션, 4D 관측 비교 중
   무엇을 중심으로 좁히는 것이 학부 연구로 가장 적절한가?
2. Sleipner 자료에서 실제로 재현 가능한 benchmark와 필요한 추가 입력은 무엇인가?
3. 최대 압력·질량수지·plume 비교에 어떤 허용 오차와 독립 검증을 적용해야 하는가?
4. 덮개암·단층·폐공의 조사 항목을 과장 없이 표현하려면 어떤 증거가 필요한가?
5. NVIDIA surrogate/agent 활용에서 연구 기여가 될 비교 실험은 무엇인가?

## 제출하고 싶은 증거

재현 실행 명령과 저장소, 데이터·가정 목록, 기준 계산과 비교 그림,
실패·미해결 항목을 담은 8–12쪽 기술보고서, 기여 기록.
본 문서는 자문을 준비하는 초안이며 지도·공동연구·공동저자 합의를 뜻하지 않는다.
