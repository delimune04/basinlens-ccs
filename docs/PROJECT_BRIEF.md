# BasinLens CCS — Subsurface Evaluation Workbench

설계 초안 · 2026-10-03 · 구현 기반 v0.2.0

## 한 문장 목표

지질·시추·지진 자료와 물리 시뮬레이션을 연결하여 CO₂ 지중저장 후보지의
**저장용량, 주입성, 압력, CO₂ 이동, 자료 부족과 불확실성**을 검토하고,
다른 연구자가 계산을 재현할 수 있는 평가 기록을 만드는 프로그램.

첫 적용 분야는 염수 대수층 CCS로 한정한다. Sleipner를 실제 자료 기반의
참조 사례로 사용하고, 지열·수소저장·석유 탐사는 공통 데이터·엔진 구조가
안정화된 뒤 별도 물리 모듈로 확장한다.

## 누구의 어떤 업무를 해결하는가

| 사용자 | 구체적인 질문 | 결과물 |
|---|---|---|
| 저장소 평가 연구자 | 어떤 가정이 저장량 차이를 만드는가? | 분포·민감도·입력 근거 |
| 저류층 엔지니어 | 주입 조건을 바꾸면 압력과 plume이 어떻게 달라지는가? | 기준 시뮬레이션과 시나리오 비교 |
| 지구물리 연구자 | 모니터 지진자료 변화가 예측 plume과 일치하는가? | QC·변화 지도·불일치와 해석 한계 |
| 검토 교수·기술 책임자 | 무엇이 관측이고 무엇이 가정이며 무엇을 검증했는가? | 근거 목록·재현 명령·검증 보고서 |

예상 업무 흐름: 프로젝트 생성 → 자료 등록/QC → 지질 가정 검토 →
기준 계산 → 제한된 시나리오 실험 → 관측과 비교 → 결과와 미해결 항목 검토.

v0.2.0은 실행 가능한 **연구용 출발점**이다. 실행 테스트 성공은 현장 검증과
다르다. 기업에서 바로 채택할 수 있는 상태는 아래 인수 기준을 통과한 뒤 판단한다.

## 첫 번째 완결된 사용 사례

**Sleipner reference study**: 공개 참조 모델의 자료·단위를 감사하고, 작은
모델의 물리 계산을 재현한 뒤 관측 plume 경계와 비교한다. 필요한 관측·주입
이력·물성이 없으면 그 사실을 기록하고, 합성 가정은 관측값과 별도 표시한다.

1. 기존 synthetic CSV로 설치와 계산·보고서 흐름을 재현한다.
2. Sleipner 참조 모델 중 작은 asset의 출처·버전·좌표·단위를 기록한다.
3. CO₂–brine 설정의 기준 시뮬레이션을 실행하고 질량·압력·격자 민감도를 확인한다.
4. 허용된 관측 경계 또는 지진자료 subset과 결과를 비교한다.
5. 기준 엔진의 검증 결과를 확보한 뒤 AI surrogate 및 자동 실험을 평가한다.

4D seismic 진폭 변화는 CO₂ 포화도나 누출 확률의 직접 측정값으로 취급하지 않는다.
자료 정렬, 취득 차이, 암석물리 가정과 비유일성을 먼저 다룬다.

## 품질 인수 기준

- 입력의 단위·좌표·출처·변경 내역과 모델 가정을 추적할 수 있다.
- 알려진 해·공개 benchmark·수치 수렴성으로 물리 엔진을 검증한다.
- 최대 압력, 주입정 주변 오차, 질량수지 등 업무와 연결된 지표를 사용한다.
- 자료가 부족하면 `unknown`/`not evaluated`를 표시하며 안전하다는 점수로 바꾸지 않는다.
- 사용자 측 검토자가 허용 오차와 적용 범위를 승인하고, 실제 사례로 pilot를 수행한다.
- 설치·재현·실패복구·접근권한·데이터 사용 조건이 문서화되어 있다.

수치 인수 기준의 제안과 검증 단계는 [VALIDATION_PLAN.md](VALIDATION_PLAN.md)에 둔다.

## 연구·CV 산출물

저장소, 재현 실행 묶음, 방법·한계·검증을 담은 기술보고서, 영어 발표자료,
작동 demo, 기여 기록을 하나의 사례에 연결한다. 현재 CV에는
“uncertainty-aware conceptual CCS screening prototype” 수준의 표현만 사용한다.
현장 검증·NVIDIA 학습·교수 자문은 실제 수행한 뒤 각각 기록한다.

본격 구현은 수능과 남은 시험 일정 종료 후 진행한다. 기존 뮤온 연구와 CCS를
동시에 대형 프로젝트로 진행하지 않고, 설계·작은 재현 과제부터 단계적으로 시작한다.
